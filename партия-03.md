## 1. Dark Souls: Remastered (2011/2018, FromSoftware + QLOC/Virtuos) — AppID 570940

- **Engine:** FromSoftware in-house (без публичного названия)
- **Format:** 3D | **World:** linear (interconnected) | **Scale:** medium
- **Platforms:** PS3 (22.09.2011 JP / 04.10.2011 NA), Xbox 360 (04.10.2011 NA), Windows (Prepare to Die 24.08.2012 NA/EU), PS4/Xbox One Remastered (24.05.2018 JP / 25.05.2018 WW), Switch Remastered (19.10.2018)
- **Targets:** 1080p / 60 fps (PS4/Win/Xbox One); 30 fps (Switch); 30 fps (PS3/360/DS1 оригинал на ПК)
- **Object/NPC level:** medium / high | **Multiplayer:** true (до 6 игроков в Remastered, до 4 в оригинале)
- **API:** DX9 (оригинал 2012); DX11 (Remastered 2018)

### Features
- character_animation, ai_pathfinding, post_processing, baked_lighting, multiplayer_netcode, dynamic_lighting

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| interconnected_world_no_warping | единый мир Lordran без warping, только unlockable shortcuts | Сложная навигация для игрока |
| bonfire_checkpoint_system | костёр = checkpoint + restore + level-up + respawn врагов | Дисциплина левел-дизайна (точки размещения) |
| humanity_online_state | форма human/hollow определяет доступ к co-op и invasion | Доп. состояние для синхронизации |
| covenant_faction_system | 9 covenants меняют multiplayer-задачи и rewards | Сложная балансировка |
| bloodstain_player_messages | оставлять сообщения "try jumping", показывать как умерли другие игроки | Серверная логика; abuse-модерация |
| invasion_asymmetric_multiplayer | PvP-инвазия в SP через matchmaking | Несбалансированный опыт у вторгнутого |
| soul_currency_xp | единая валюта для level-up + покупок + upgrade | Потеря souls при смерти — высокий риск |
| weapon_art_two_hand | удержание двух рук меняет move-set | Больше анимаций для каждого оружия |
| parry_riposte_system | парирование открывает окно для riposte (критический удар) | Тайминг-зависимый |
| stats_vit_end_str_dex_int_fth | 8 характеристик + attunement | Долгий выбор билда |
| magic_attunement_slots | вместо mana — лимит использований заклинаний | Контент-дизайн балансирует |

### Инженерный паспорт
- **Min HW (оригинал 2012):** Core 2 Duo E6600 / Athlon 64 X2 5600+, 2 GB RAM, GeForce 8600 / Radeon HD 3850
- **Rec HW:** Quad-core, 4 GB RAM, GeForce 9800 / Radeon HD 4870
- **Frame budget:** 33.3 мс (оригинал 30 fps); 16.6 мс (Remastered 60 fps)
- **Streaming/IO:** цельный мир Lordran, разбит на чанки для загрузки; loading screens только между областями
- **Engine limits:** **Havok Physics: дефект детерминизма симуляции при отвязке от 30 fps через DSFix** — удвоение тиков приводило к сокращению дистанции прыжка и проваливанию персонажа сквозь текстуры при спуске по вертикальным лестницам. QLOC выполнил полную переработку физических констант в Remastered (2018). Оригинал DSFix — фиксированное render resolution 1024x720; ПК-порт 2012 года был плохо оптимизирован.
- **Display:** **программная блокировка соотношения сторон 21:9** (чёрные полосы) и **кап 60 fps** — ради паритета в сетевых вторжениях
- **Mod support:** DSFix (unofficial), community-моды для PTDE; Remastered имеет встроенный 60 fps
- **Antipiracy:** Games for Windows — Live (PTDE 2012, устарел); Steamworks (после миграции декабрь 2014)

### Баланс решений
- **Выгода:** костёр как save+story+atmosphere; interconnected world создаёт метрики исследования; bloodstains/community messages — асинхронная социализация
- **Цена:** PTDE 2012 имел фиксированный render resolution (нужен DSFix); ограничение на 4 игроков в кооп; PvP-инвазии могут разрушить опыт SP

### Инженерно значимые патчи
- Октябрь 2012: Artorias of the Abyss DLC (консоли)
- 24.08.2012: Windows порт (PTDE) — провал качества, фиксированное разрешение
- Декабрь 2014: миграция с Games for Windows Live на Steamworks (с сохранением сейвов)
- Февраль 2015: Steamworks стал стандартом
- Апрель 2016: Xbox 360 версия через backward compatibility на Xbox One
- 25.05.2018: Dark Souls Remastered (PS4/Win/Xbox One) с 60 fps и dedicated servers
- 19.10.2018: Switch-версия (30 fps, порт от Virtuos)
- Январь 2022: PC-серверы PTDE отключены после security exploit (RCE)
- Ноябрь 2022: Remastered PC multiplayer восстановлен

## 2. Dark Souls II: Scholar of the First Sin (2014/2015, FromSoftware) — AppID 335300 (SotFS) / 236430 (оригинал)

- **Engine:** FromSoftware in-house (новая версия для DS2, директор Tomohiro Shibuya, не Миядзаки)

- **Targets:** 1080p / 60 fps (SotFS); 30 fps (PS3/360)
- **Object/NPC level:** high / high | **Multiplayer:** true (до 6 в SotFS)

### Features

- **Min HW:** Core 2 Duo E6600 / Athlon 64 X2 5600+, 2 GB RAM, GeForce 8600 / Radeon HD 3850 (оригинал)

### Баланс решений
- **Выгода:** Soul Memory более справедливый matchmaking; NG+ создаёт долгосрочный контент
- **Цена:** frame-rate-dependent durability баг (известный >года); директор не Миядзаки; потеря сохранений при upgrade; баланс boss-файтов хуже DS1

### Инженерно значимые патчи

- 26.08.2014: Crown of the Old Iron King (DLC)
- 30.09.2014: Crown of the Ivory King (DLC)

- **Выгода:** открытый мир с свободой исследования; вертикальность Torrent; stealth из Sekiro; spirit summon расширяет кооп; GRRM даёт глубину lore

- 20.06.2024: Shadow of the Erdtree DLC (крупнейшее DLC FromSoftware — продано 10 млн)
- 28.08.2026: Tarnished Edition на Switch 2 (2 новых класса + Torrent скины + DLC перекрёстно)
- Анонс фильма: A24 + Garland (март 2028)
- Elden Ring Nightreign (2025) — multiplayer-focused spinoff

## Замечания о движке

FromSoftware **не публикует** официальное название движка (исключая LORE у Firaxis). В литературе:
- DS1-3 + Sekiro + ER = семейство in-house engines с большой степенью наследования
- AC1-6 = отдельное семейство (AC V был на собственном движке, AC VI — продолжение)
- Bloodborne = побочная ветвь (на PS4 эксклюзив)

**Технические решения, общие для всех:**
- Havok как middleware для физики (DS1-3, Sekiro, ER)
- Собственный уровень streaming для мира
- Собственный AI (патрулирование по NavMesh + ручные триггеры)
- Собственный animation blending (преимущественно)

**Общие проблемы:**
- Плохая оптимизация на релизе (DS1 PTDE, ER, ER на PS4)
- Отсутствие официальной поддержки модов через Workshop
- ~~Denuvo ломает performance на релизе (DS3, Sekiro, ER)~~ **ОПРОВЕРГНУТО: Denuvo НЕ использовался ни в одной из этих игр** (подтверждено SteamDB, импортом библиотек и обсуждениями на playground.ru/quora)
