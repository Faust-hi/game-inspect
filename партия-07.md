## Замечания о id Software и их технических проблемах

**Сильные стороны id Tech:**
- Исторические лидеры в оптимизации FPS (Quake, Doom, Rage)
- MegaTexture — инновация в стриминге текстур
- Превосходный push-forward combat (DOOM 2016, Eternal)
- Vulkan API поддержка через патчи
- Возврат к геймплею после провала Doom 4 (Call of Doom) — "Reboot" подход
- 30+ лет опыта

**Слабые стороны id Tech:**
- Doom 4 (Call of Doom) провалился — 4 года разработки
- Rage (2011) — катастрофический PC-релиз
- Quake Champions — отказ от моддинга (Quake-сообщество в шоке)
- Переход с Bethesda Softworks на Microsoft (2021) — будущее движков под вопросом
- Rage 2 (2019) — аутсорс Avalanche, не id Tech
