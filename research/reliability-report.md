### 2.6 Найденный и исправленный дефект: профиль команды `custom`

При сверке требований спецификации с кодом обнаружено расхождение, которое
ранее не всплывало, потому что не проявлялось как ошибка.

- **Требование**: профили команды `solo`, `small_2_5`, `mid_6_15`,
  `large_16_plus`, **`custom`**.
- **Факт**: профиля `custom` не существовало ни в сиде, ни в `DEFAULT_TEAMS`.
- **Почему это было опасно**: `team_for()` для любого неизвестного кода молча
  возвращал `small_2_5` **под кодом `small_2_5`**. Запрос `team=custom` не
  падал и не предупреждал — пользователь получал календарь малой команды,
  считая его своим. Это ровно тот класс дефекта, который проект объявляет
  недопустимым: отсутствие данных выдаётся за данные.

Исправление:
1. Профиль `custom` добавлен в `TEAM_RECORDS` (сид) и `DEFAULT_TEAMS` — нейтральная
   ёмкость (6 человек, 3 потока), описание прямо называет значения экспертным
   допущением, а не измерением;
2. `team_for()` больше не подменяет код: неизвестный профиль возвращается под
   своим кодом, а описание сообщает о подстановке явно;
3. Добавлены 2 регрессионных теста; оба проверены mutation-пробой (возврат к
   старому поведению → тест падает).

После правки: **91 backend-тест**, профиль `custom` присутствует в
`/api/catalog/teams` и в разделе 13.1 отчёта.

## 4. Перепроверка сетевых находок (независимым путём)

Механическая проба идёт через прокси песочницы (`127.0.0.1:65279`). Прямое
соединение заблокировано, поэтому часть запросов падает как `502 Bad Gateway`
(туннель) — это отказ **сети**, а не битая ссылка. Чтобы не принять сетевой шум
за дефект данных, каждая группа находок перепроверена независимо.

| Группа | n | Проба через прокси | Независимая проба | Вердикт |
|---|---|---|---|---|
| `error` (502/tunnel, TLS) | 27 | 502 / timeout | `recastnav.com` → **живая** (полный контент); `docs.unity.cn/…/CharacterRig.html` → **200** ×3; DNS резолвится | **ложные**, ссылки живые |
| `protected` (403/429) | 19 | 403 / 429 | `minecraft.wiki/w/chunk` → **живая** (полный контент); 403 и с браузерным UA | **бот-стена**, не мёртвая ссылка |

Пример независимого подтверждения: `https://recastnav.com/` внутри песочницы
даёт `502 Bad Gateway`, а через внешний канал отдаёт полную страницу Recast
Navigation. Аналогично `https://minecraft.wiki/w/chunk` при `403` через прокси
доступна внешне и описывает чанки Minecraft.

**Итог: по результатам перепроверки — 0 заведомо мёртвых ссылок.**
Ранее исправленные 5 битых ссылок заменены на пробитые 2xx-эквиваленты
(`repair_verification_findings.py`), повторно не всплыли.

## 5. Незыблемые принципы (соблюдены)

1. **Отсутствие источника ≠ совместимость.** Нет доказательства → явная запись-пробел, а не домысел.
2. **`derived` требует формулу + входные параметры.** Качественное рассуждение — это `documented` или `unknown`; таких нарушений 0.
3. **URL никогда не выдумывается.** Замена — только на пробитый 2xx-эквивалент.
4. **Прямой пример ≠ перекрёстный.** Инструмент без прямого примера обязан объявить пробел.
5. **Reference-реализации — не игровые примеры.**
6. **Регистр URL важен.** Дедупликация без учёта регистра, проба — с оригиналом.
