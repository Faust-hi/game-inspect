## 1. Assassin's Creed Unity (2014, Ubisoft Montreal) — AppID 289650

- **Engine:** AnvilNext 2.0 (новая версия для PS4/Xbox One/PC)
- **Format:** 3D | **World:** open_world (Paris 1:1, 7 districts) | **Scale:** medium
- **Platforms:** PS4 (11.11.2014 NA, 14.11.2014 UK), Xbox One, Windows (release day)
- **Targets:** 1080p / 30 fps (на старте); позже патч до 60 fps на PS5/Xbox Series
- **Object/NPC level:** very_high (30,000 NPC на экране) / high | **Multiplayer:** true (до 4 игроков)

### Features
- character_animation, ai_pathfinding, post_processing, dynamic_lighting, multiplayer_netcode (новый), nvidia_gameworks_partnership

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| crowd_30000_npc | до 30,000 NPC в одной сцене с индивидуальным AI | Рекордная нагрузка на CPU |
| paris_1_to_1_scale | реальные размеры Парижа | Сложнее навигации и оптимизации |
| black_box_mission_design | множество путей прохождения миссий (отход от линейности) | Контент-дизайн дороже |
| free_run_up_down_commands | новые команды для вертикального паркура | Доп. анимации |
| crowd_activities_interaction | NPC органично предлагают действия | AI overhead |
| cafe_theatre_upgrade_economy | внутриигровая экономика (кафе как HQ) | UI overhead |
| coop_mission_4p | кооперативные миссии до 4 игроков | Дополнительный netcode |
| nvidia_gameworks_partnership | TXAA, tessellation, PhysX | Vendor lock-in |
| hair_works_fur | GameWorks hair/fur (после исправлений) | Изначально баг — удалили |
| day_night_cycle_paris | 24-часовой цикл в большом городе | Стоимость симуляции NPC |
| procedural_paris_buildings | некоторые здания созданы процедурно | Уникальные баги |
| weather_time_anomalies | путешествие во времени через разные эпохи | Требует отдельных уровней |
| c ++ _c_sharp_codebase | 15.5M строк C++ + 5M строк C# | Гибридный монолит, сложно дебажить |
| noshader_optimization | сначала DX11, но оптимизировано под 900p на консолях | Ограниченный бюджет на рендер |

### Инженерный паспорт
- **Min HW (PC):** Core i5-2500K / AMD FX-6350, 6 GB RAM, GeForce GTX 660 / Radeon R9 270X
- **Rec HW:** Core i7-4790 / AMD FX-8350, 8 GB RAM, GeForce GTX 780 / Radeon R9 290X
- **Frame budget:** 33.3 мс (30 fps) из-за crowd 30,000 NPC
- **Streaming/IO:** большие зоны Paris 1:1, сложный streaming между districts
- **Engine limits:** **архитектурная первопричина: симуляция 30 000 NPC + детализированная архитектура Парижа генерировала свыше 50 000 draw calls на кадр**. Конвейер DirectX 11 с его монопотоком отрисовки парализовал ядра CPU. PS4/Xbox One CPU лимит → crowd AI дорогой; game-breaking баги на релизе
- **Кодовая база:** 15.5M строк C++ + 5M строк C# (CppCon доклад архитектора Ubisoft Николя Флёри: hybrid monolith, рендер/skel-blend/pathfinding/ИИ в unmanaged C++, gameplay/tools/редакторы в C#)
- **Mod support:** нет официального SDK
- **Antipiracy:** Uplay/Ubisoft Connect (требуется online активация)

### Баланс решений
- **Выгода:** самый детализированный Paris на релизе; революционная crowd AI; Black Box missions
- **Цена:** печально известный багнутый релиз (frame drops, NPC popping, face glitch); Ubisoft извинилась; Dead Kings DLC бесплатно

### Инженерно значимые патчи (ПК)
- 14.11.2014: day-one patch с попыткой исправления багов
- 18.11.2014: первый hotfix
- 24.11.2014: убрали GameWorks HairWorks (только ухудшал ситуацию)
- 2015-2016: 7 патчей исправляющих производительность
- 12.02.2015: patch убирает требование Companion App
- Март 2026: 4K/60 FPS на PS5/Xbox Series (2026)

## 2. Assassin's Creed Origins (2017, Ubisoft Montreal) — AppID 575560

- **Engine:** AnvilNext 2.0 (после Unity, переработан с фокусом на RPG)
- **Format:** 3D | **World:** open_world (Египет, Птолемеевский период) | **Scale:** very_large
- **Platforms:** PS4 (27.10.2017), Xbox One, Windows
- **Targets:** 1080p / 30 fps (PS4); 4K / 30 fps (PS4 Pro)
- **Object/NPC level:** high / high | **Multiplayer:** false (полностью SP)

### Features
- character_animation, ai_pathfinding, post_processing, particle_systems, particle_systems (Sensua Engine), procedural_generation

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| hitbox_combat_system | hit-box вместо paired animation (как в Souls) | Удорожание AI и анимаций |
| procedural_world_generation | procedural generation для пустынь и NPC поведения | Доп. QA |
| eagle_senu_companion | орёл Сену вместо Eagle Vision — отдельный AI | Удвоенный render для sky+terrain |
| skill_tree_three_branches | Hunter/Warrior/Seer — 3 отдельных древа | Контент-дизайн |
| level_recommendation_areas | зоны с рекомендованным уровнем (как в MMO) | Ограничивает исследование для слабых игроков |
| procedural_side_quests | 20,000 строк диалогов + procedurally generated квесты | Риск повторений |
| engwe_sensua_animations | новая система анимации от Ubisoft (Sensua) | Удвоенный объём анимаций |
| dynamic_schedule_npcs | NPC имеют ежедневный распорядок (работа → сон) | AI overhead, но оправдано |
| compass_replaces_minimap | компас вместо мини-карты (минимизация HUD) | UI переработка |
| mount_horse_camel_chariot | разные маунты | AI overhead на разные маунты |
| crafting_resources | выделанные ресурсы для крафта | Дополнительный item-база |
| loots_boxes_limited_in_game | loot boxes только за in-game currency (позже лутбоксы-скандал) | Монетизация-критика |
| underwater_exploration_first_time | первое подводное плавание в серии со времён Black Flag | Доп. cost |
| boss_phylakes_high_level | высокоуровневые "Phylakes" как боссы | Доп. контент-дизайн |
| taming_predators | приручение хищников (львы, крокодилы) | AI overhead |

### Инженерный паспорт
- **Min HW (ПК):** Core i5-2400s / AMD FX-6350, 6 GB RAM, GeForce GTX 660 / Radeon R9 270X
- **Rec HW:** Core i7-3770 / AMD FX-8350, 8 GB RAM, GeForce GTX 760 / Radeon R9 280X
- **Frame budget:** 33.3 мс (30 fps) — больше не на 60 fps как Unity
- **Streaming/IO:** open world streaming; loading screens только между зонами
- **Engine limits:** **Denuvo + VMProtect (двухслойный обфускатор)**: поверх Denuvo Anti-Tamper наложен VMProtect, создающий непрерывную нагрузку на расшифровку инструкций в цикле — 100% утилизация 4-ядерных Intel Core i5; PS4 RAM ограничивает streaming
- **Mod support:** нет официального SDK
- **Antipiracy:** Uplay/Ubisoft Connect + Denuvo + VMProtect (двухслойная цепочка, Origin-уровень нагрузки на CPU)

### Баланс решений
- **Выгода:** переход к RPG-формату; египетские консультанты для аутентичности; combat overhaul; Discovery Tour (обучающий режим)
- **Цена:** переход к RPG потерял stealth-фокус оригинала; grind-элементы из MMO; продажа XP-бустеров

### Инженерно значимые патчи
- Декабрь 2017: патч 1.10 — Nightmare difficulty, "Here Comes a New Challenger" миссия
- Январь 2018: The Hidden Ones DLC
- Февраль 2018: Discovery Tour, New Game Plus
- Март 2018: The Curse of the Pharaohs DLC
- Апрель 2018: Animus Control Panel для ПК (читы)
- Июнь 2022: 60 FPS patch на PS5/Xbox Series
- Удалён Denuvo DRM
