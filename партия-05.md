## 1. The Elder Scrolls V: Skyrim Special Edition (2011/2016, Bethesda Game Studios) — AppID 489830 (SE)

- **Engine:** Creation Engine (форк Fallout 3 Gamebryo)
- **Format:** 3D | **World:** open_world (Skyrim 9 holds, 37 кв. миль по словам Howard) | **Scale:** very_large
- **Platforms:** PS3 (11.11.2011), Windows, Xbox 360 (оригинал); PS4/Xbox One (28.10.2016 SE); Switch (17.11.2017); PS5/Xbox Series X|S (11.11.2021, через Anniversary); Switch 2 (09.12.2025)
- **Targets:** 1080p / 30 fps; SE — 4K на PS4 Pro/Xbox One X
- **Object/NPC level:** high / high | **Multiplayer:** false (Skyrim Together Reborn — мод)

### Features
- character_animation, ai_pathfinding (Radiant AI), procedural_quests (Radiant), post_processing, modding_ecosystem

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|

### Инженерный паспорт
- **Min HW (оригинал 2011):** Core 2 Duo / Athlon X2 2.0 GHz, 2 GB RAM, GeForce 8800 / Radeon X1900 (512 MB)
- **Rec HW (оригинал):** Core i5 / Phenom II, 4 GB RAM, GeForce GTX 260 / Radeon 4890
- **Min HW (SE 2016):** Core i5-750 / AMD Phenom X4, 8 GB RAM, GeForce GTX 470 / Radeon HD 7870 (2 GB)
- **Rec HW (SE):** Core i5-2400 / AMD FX-8320, 8 GB RAM, GeForce GTX 770 / Radeon R9 280X (4 GB)
- **Frame budget:** 33.3 мс (30 fps) на консолях; SE — 4K. **Havok timer жёстко привязан к 60 fps**: при частотах свыше 60 Гц физика теряла устойчивость (предметы в интерьерах приобретали сверхвысокие скорости, нанося урон игроку — типичная проблема Creation Engine без фиксированного delta-time)
- **Streaming/IO:** World partition — cell-based loading
- **Engine limits:** **критический лимит памяти в оригинальной версии 2011 года: 3.1 ГБ виртуального адресного пространства (32-bit)**, приводил к крушению движка при установке тяжёлых пакетов текстур до выхода Special Edition. PS3 RAM — 256 MB split (знаменитые save size лимиты)
- **Mod support:** ОТЛИЧНОЕ (Creation Kit + Workshop + Nexus Mods)
- **Antipiracy:** Steamworks

### Баланс решений
- **Выгода:** Radiant AI + Radiant Quests дают бесконечный контент; модинг = вечная жизнь игры; open world с реальной физикой ветра/воды
- **Цена:** PS3 RAM constraints → save > 6MB = CTD; баги на релизе (физика, меши); печально известные save size лимиты

- **Rec HW:** Core i7-4790 / AMD FX-9590, 8 GB RAM, GeForce GTX 780 / Radeon R9 290X (3 GB)
- **Frame budget:** 33.3 мс (30 fps)
- **Streaming/IO:** cell-based world partition; load screens между cells. **Precombines + Previs**: статическая видимость (precomputed visibility) + precombines (предкомбинированные меши статичной геометрии интерьеров) — попытки моддеров отключить precombines для изменения интерьеров **приводили к полному отказу окклюзии и падению fps в Бостоне до 15 fps**

- **Mod support:** ОТЛИЧНОЕ (Creation Kit)
- **Antipiracy:** Steamworks

### Баланс решений

- **Цена:** упрощённый RPG (по сравнению с New Vegas); dialog wheel вместо camera-zoom; упрощённый character build

## Ключевые новые методы для DSS

- `radiant_ai` (Skyrim+, FO) — NPC с расписанием
- `radiant_quest` (Skyrim+, FO) — процедурные побочные квесты
- `havok_behavior_toolset` (Skyrim+) — плавный переход анимаций
- `dual_wielding` (Skyrim+) — два предмета в руках

## Замечания о Bethesda и технических проблемах

**Общая проблема:** Creation Engine — это маркетинговое название для форка Gamebryo, который сам основан на NetImmerse 1997 года. Код Morrowind (2002) до сих пор присутствует в Starfield (2023). Это объясняет:
- Почему Bethesda всегда отстаёт по оптимизации
- Почему баги на релизе у всех их игр
- Почему Creation Engine 2 в Starfield — это не полный переписанный движок, а эволюция
- Почему FO76 пришлось ретрофитить netcode (использовали Quake)
- Почему Skyrim SE / FO4 next-gen patches поломали моды

**Хорошая новость:** Bethesda AСоздаёт самые модд-friendly игры (Skyrim — рекордсмен Steam Workshop), что компенсирует техническую отсталость комьюнити-патчами.
