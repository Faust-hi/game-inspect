## 1. Cyberpunk 2077 (2020, CD PROJEKT RED) — AppID 1091500

- **Engine:** REDengine 4 (последняя итерация; дальше — переход на UE5 для Orion)
- **Format:** 3D | **World:** open_world (Night City, вертикальный плотный город) | **Scale:** very_large
- **Platforms:** PC + PS4/Xbox One (10.12.2020), PS5/XSX (02.2022, патч 1.5), Switch 2 (2025)
- **Targets:** 1080p–4K / 30–120 fps (зависит от RT/апскейла)
- **Object/NPC level:** very_high / very_high (толпы, трафик) | **Multiplayer:** false (сингл; мультиплеер отменён)

### Features
- open_world_streaming, crowd_ai, ray_tracing_path_tracing, temporal_upscaling, vehicle_physics

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| redengine4_streaming_nightcity | потоковый Night City без швов, district-чанки + вертикальные слои | CPU-bound на HDD |
| crowd_traffic_density_system | сотни NPC + трафик с LOD поведения | Главный потребитель CPU |
| rt_overdrive_path_tracing | RT Overdrive (патч 2023): полный path tracing вместо гибридного RT | Только RTX 40xx + DLSS 3 FG для 60 fps |
| dlss3_fg_ray_reconstruction | DLSS 3.5 Ray Reconstruction + Frame Generation | Vendor lock-in NVIDIA |
| smt_ryzen_fix_2_0 | патч 2.0: нативная поддержка SMT на Ryzen (раньше требовался мод) | Перебалансировка тредов |
| hybrid_cpu_p_governor_2_11 | патч 2.11 (01.2024): Hybrid CPU Utilization — Auto / Prioritize P-Cores для Intel 12/13/14 gen (Gameplay → Performance) + фикс RX Vega; в 2.11 на i9-13900K+RTX 4080 Super — микростаттеры (Tom's Hardware), пофикшены в 2.12 | Ручной оверрайд планировщика Windows |
| police_system_rework_2_0 | переписанная полиция + погони (Phantom Liberty) | Дороже AI |
| vehicle_combat_rework | стрельба из машин, quickhack в движении | Доп. анимации |
| hdd_to_ssd_mandatory | после 2.0 HDD официально не поддерживается — только SSD | Отсечение слабого железа |

### Инженерный паспорт
- **Min HW (релиз 2020):** Core i5-3570K / FX-8310, 8 GB RAM, GTX 780 / RX 470, HDD
- **Min HW (2.0/PL 2023):** Core i7-6700 / Ryzen 5 1600, 12 GB RAM, GTX 1060 6GB / RX 580, **SSD обязателен**
- **Rec HW (RT Overdrive):** Core i9-12900 / Ryzen 9 7900X, 16 GB RAM, RTX 4080+, NVMe
- **Frame budget:** 16.6 мс (60 fps raster); 33.3 мс (30 fps RT на консолях); path tracing — только с FG
- **Streaming/IO:** district-чанки Night City; на HDD — статтеры текстур (исправлено отказом от HDD)
- **Engine limits:** REDengine 4 — последний; дальше Orion на UE5. CPU 90% на 8 ядрах в Dogtown (Pierściński, 09.2023)
- **Mod support:** REDmod (официальный, 2022) + ArchiveXL; нет Workshop
- **Antipiracy:** Steam/GOG DRM-free + Denuvo отсутствует (GOG); Steam-версия — Steamworks

### Баланс решений
- **Выгода:** Night City — самый плотный город поколения; RT Overdrive — витрина path tracing
- **Цена:** релиз 12.2020 — провальный (возвраты, снятие с PS Store до 06.2021); старая CPU-архитектура без SMT; HDD-статтеры

### Инженерно значимые патчи (ПК)
- 10.12.2020: релиз 1.0 — провальный (баги, T-pose, полиция-спавн, 8 МБ сейв-коррапт)
- 12.2020–01.2021: хотфиксы 1.04–1.06 (стабильность, сейвы)
- 02.2022: патч 1.5 — PS5/XSX некстген, FSR 1.0
- 09.2022: 1.6 — FSR 2.1, XeSS
- 04.2023: RT Overdrive (path tracing preview) + DLSS 3
- 09.2023: **2.0 + Phantom Liberty** — SMT Ryzen нативно, полиция, скиллы, SSD mandatory, 90% CPU на 8 ядрах
- 12.2023: 2.1 — метро, портативный радио, accessibility
- 01.2024: **2.11 — Hybrid CPU Utilization (P-Cores)**; 03.2024: 2.12 — фикс микростаттеров 2.11
- 12.2024: 2.2 — кастомизация авто, фоторежим

### Источник
- Tom's Hardware (Phantom Liberty CPU 90%, patch 2.11/2.12 hybrid CPU), KitGuru, TechSpot Optimization Guide 2.0, OC3D, CDPR патчноуты

## 2. Overwatch → Overwatch 2 (2016/2022, Blizzard) — AppID 2357570 (OW2)

- **Engine:** собственный in-house (Overwatch Engine → **Overwatch Engine 2.0**, не UE5)
- **Format:** 3D | **World:** arena (карты 5v5/6v6) | **Scale:** small
- **Platforms:** PC + PS4/Xbox One/Switch (OW1 2016); PC + PS5/XSX/Switch (OW2 10.2022, F2P)
- **Targets:** 1080p–1440p / 60–120+ fps (компетитив — 144+ fps на ПК)
- **Object/NPC level:** low / medium (12→10 игроков) | **Multiplayer:** true (компетитивный шутер)

### Features
- tickrate_netcode, rollback_favor_shooter, hero_abilities, ecs_simulation

- **Min HW (OW1 2016):** Core i3 / Phenom X3, 4 GB RAM, GTX 460 / HD 4850
- **Min HW (OW2 2022):** Core i3-12100 / Ryzen 3, 6 GB RAM, GTX 600 / HD 7000
- **Rec HW (144 fps):** Core i7 / Ryzen 7, 8 GB RAM, GTX 1060 / RX 580+
- **Frame budget:** 8.3 мс (120 fps компетитив); 16.6 мс (60 fps казуал)
- **Streaming/IO:** арены целиком, без стриминга мира
- **Engine limits:** 5v5 — техно-экономика: 12 игроков не держат 120 fps на старом железе с новыми фичами (контуры, healer vision); возврат 6v6 требует сезонов оптимизации (Keller, 07.2024)
- **Mod support:** нет (Workshop — скрипты режимов, не ассеты)
- **Antipiracy:** Battle.net + kernel античит

### Баланс решений
- **Выгода:** отзывчивость как религия; F2P + кроссплей + кросс-прогресс
- **Цена:** отмена PvE; 5v5 расколол комьюнити; баланс танков переписан

### Инженерно значимые патчи
- 05.2016: OW1 релиз (6v6, loot boxes)
- 2019 (BlizzCon): OW2 анонс — Engine 2.0, PvE, большие карты
- 10.2022: OW2 релиз (F2P, 5v5, OW1 выключен, очереди 40k, DDoS)
- 2023: отмена PvE-талантов (репутационный удар)
- 2023–2024: сезоны героев, balance, netcode-фиксы
- 07.2024 (Keller): возврат 6v6 тестируется, но требует сезонов оптимизации под Switch/PS4

### Источник
- Overwatch2Hub (Engine 2.0, netcode −30%), Polygon (6v6 возврат, Keller 07.2024), Tweaktown (BlizzCon 2019 engine upgrades), Blizzard patch notes 2023

## 3. Minecraft: Java Edition + Bedrock (2011–…, Mojang) — AppID нет (лаунчер)

- **Engine:** Java Edition (Java, LWJGL/OpenGL) vs Bedrock (C++, RenderDragon)
- **Format:** 3D voxel | **World:** infinite procedural (сид-генерация) | **Scale:** infinite
- **Platforms:** PC Java (2009–), PC Bedrock/Win10 (2015–), консоли, мобайл
- **Targets:** 1080p / 30–240 fps (зависит от дальности и модов)
- **Object/NPC level:** medium / low | **Multiplayer:** true (серверы, Realms)

### Features
- voxel_chunks, procedural_generation, mod_api_fabric_forge, crossplay_bedrock

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| java_gc_stutter_early | ранние версии: Java GC-паузы + single-thread чанки → просадки на слабом железе | Родовая боль Java |
| rewrite_chunk_render_1_8_1_15 | 1.8–1.15: переписывание чанк-рендера, VBO, frustum culling | Ломало моды (OptiFine) |
| sodium_lithium_modern_fix | Sodium (рендер, 221.8M загрузок на Modrinth) + Lithium (тик) + Phosphor (<1.19): кратный рост fps на том же железе без потери картинки; 0.9.x (06.2026) — ранний Vulkan-бэкенд | Только Fabric/NeoForge/Quilt, GL 4.5+; Android/ARM через трансляторы не поддерживается |
| bedrock_renderdragon_rewrite | Bedrock: RenderDragon (DX12/GL) вместо старого GL — +fps, но сломал шейдеры | Потеря кастомных шейдеров |
| java_17_21_migration | 1.18+ → Java 17, 1.21+ → Java 21: ZGC/Generational GC, меньше пауз | Требования к лаунчеру |
| simulation_distance_split | разделение render distance / simulation distance (тикаются только ближние чанки) | Сложность для ферм |
| village_pillage_raid_lag | рейды + сотни сущностей в одном чанке → TPS-просадки даже на серверах | Вечный налог песочницы |

### Инженерный паспорт
- **Min HW (Java, ранние):** Core 2 Duo, 2 GB RAM, Intel HD (20–30 fps, короткие чанки)
- **Min HW (Java 1.20+):** Core i3, 4 GB RAM, Intel UHD / GTX 700 (60 fps на 8–12 чанков)
- **Rec HW (Sodium, 24+ чанка):** Core i5 / Ryzen 5, 8 GB RAM, GTX 1060 / RX 580 + Sodium
- **Frame budget:** 16.6 мс (60 fps); TPS-сервер — 50 мс тик (20 TPS)
- **Streaming/IO:** чанки 16×16, генерация на лету; на HDD — фризы генерации (SSD решает)
- **Engine limits:** Java single-thread наследие (мировой тик + часть генерации); дальность 32+ чанков упирается в CPU/RAM, а не GPU
- **Mod support:** эталон UGC (Forge/Fabric + CurseForge/Modrinth); Bedrock — Marketplace + Add-Ons
- **Antipiracy:** Microsoft Account + лаунчер-энтайтлмент

### Баланс решений
- **Выгода:** бесконечный мир из сида; моды чинят перфоманс лучше издателя (Sodium — стандарт)
- **Цена:** Java GC-наследие; Bedrock RenderDragon сломал шейдеры; версии дробят комьюнити (Java vs Bedrock)

### Инженерно значимые патчи
- 2011: релиз 1.0 (Java, Notch) — GC-статтеры, дальность 8–16 чанков
- 1.8 (2014): новый чанк-рендер (VBO)
- 1.13 (2018): Flattening (ID-перепись, ломает моды)
- 1.15 (2019): пчёлы + перф-фиксы чанков
- 2020+: Sodium/Lithium/Starlight — community-перфоманс (не Mojang)
- 1.18 (2021): Java 17, новый генератор мира (глубина −64/+320)
- Bedrock 2022–2023: RenderDragon на всех платформах
- 1.20–1.21 (2023–2024): Java 21, simulation distance, trial chambers

### Источник
- Знания модели + прошлый аудит (Sodium/OptiFine замеры, Far Lands float32/int32, GC Stop-the-World); требуют DF/DSOG-кроссчека при калибровке

| 32bit_deprecation_2_20 | 2.20 — последний релиз с 32-bit (frozen legacy branch, без MP-совместимости); дроп Win7/8 | Отсечение легаси |
