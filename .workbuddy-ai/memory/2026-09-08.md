## Детальный анализ причин неточности (без исправлений)

### Фундаментальная причина: модель forward-looking, а не historical

Модель отвечает на вопрос «сколько ресурсов нужно **сегодня**, чтобы отрендерить такую сцену?», а не «сколько было нужно **в год релиза**?». У неё нет входа «год выпуска игры», и все константы откалиброваны на современные движки/ОС.

### A. Завышение для ретро (до 2015) — RAM / VRAM

**Механизм 1 — константные floor-компоненты памяти:**
- `system.ram = 2.5 GB` (отражает современную ОС + драйверы)
- `engine.ram = 2.0 GB` (современный движок)
- `render_targets.vram = 1.8 GB` (1080p буферы с MSAA/depth)
- `audio.ram = 0.35+ GB`
- `mirror.ram = 0.25 * (meshes.vram + textures.vram)`

Даже для самой простой игры (content=1, 1080p, high, нет стриминга) сумма даёт ~8.3 GB RAM и ~5.3 GB VRAM. Portal 2007 реально требовал 512 MB RAM, но модель не может дать меньше 8 GB — floor слишком высок.

**Механизм 2 — нет эпохового множителя для компонентов:**
Текстуры 2007 года были 512×512/1024×1024, сегодня — 4K. Модель не уменьшает `tex_res` и `tex_quality` для старых игр, потому что не знает года.

### B. Перескок CPU/GPU для ретро — на 10+ лет

**Механизм — каталог hardware.json не содержит записей старше 2016 (GPU) и 2017 (CPU):**
- Минимальный GPU: GTX 1050 Ti (2016, raster_score 0.13)
- Минимальный CPU: Core i3-8100 (2017, single_thread_score 0.47)

Даже если raster_index = 0.01 (Portal), `_pick_gpu` выбирает минимальную карту из каталога, покрывающую этот индекс — и попадает на 2016–2017 год. Нет записей для GeForce 6600 (2004), Radeon X1600 (2006), Core 2 Duo (2008).

### C. Занижение для некоторых современных (2020+) — RAM

**Механизм 1 — target_quality всегда "high" в парсере:**
В `run_batches.py:profile_of` жёстко задано `"target_quality": "high"`. Реальные rec-требования для DOOM Eternal, BF 2042, Elden Ring обычно соответствуют ultra/high+ настройкам, но модель не знает об этом. Если бы quality был "ultra", текстуры дали бы больше RAM.

**Механизм 2 — content-коэффициенты недостаточно агрессивны для специфических движков:**
- DOOM Eternal (id Tech 7, megatexture streaming) — модель считает textures по формуле `2.2 * content * tex_quality * tex_res`, но не учитывает megatexture-кэш, который в реальности требует больше RAM.
- Armored Core VI — functions парсятся скудно (FromSoftware, не все функции описаны в партиях), content может быть занижен.

**Механизм 3 — RAM_OVER_VRAM_RESERVE_GB = 4.0:**
`ram_gb = max(raw_ram, vram_gb + 4.0)`. Для AC VI: vram модель оценила в 5.4 GB, поэтому RAM = max(raw_ram, 9.4). raw_ram оказался ≈9.4, но реальный min = 12 GB. То есть raw_ram (сумма компонентов) недостаточна — компоненты занижены.

### D. CPU иногда старше игры (Alan Wake 2 2023 → i5-8400 2017)

**Механизм — CPU подбирается по индексам, но игра GPU-bound:**
- Alan Wake 2 — path tracing + mesh shaders → высокий raster_index/rt_index → выбирается мощный GPU (RTX 4080).
- Но st_index/mt_index остаются низкими (CPU-подсистемы не нагружены так сильно).
- `_pick_cpu` выбирает минимальный CPU, покрывающий индексы — и попадает на i5-8400 (2017), потому что его single_thread_score 0.5 достаточен для низкого st_index.
- Модель не учитывает, что современные AAA с path tracing требуют CPU не старше 3–4 лет относительно GPU, даже если чистые индексы «проходят».

### E. Структурная проблема парсера

- `target_quality` всегда "high" — неизвлекается из партий.
- `vram_limit_gb` и `ram_limit_gb` всегда `None` — модель использует MEMORY_NORM_VRAM_GB = 8.0 / MEMORY_NORM_RAM_GB = 16.0, но эти нормативы влияют только на memory_pressure, не на оценку объёма.
- `object_count_level` / `npc_count_level` берутся из партий, но часто default = "medium", что может занижать content для некоторых игр.

### Итог

Неточности имеют **три независимые корневые причины**:
1. **Отсутствие исторического слоя** — модель не знает года выпуска и не может масштабировать константы/каталог назад.
2. **Каталог hardware ограничен 2016+** — нет записей для ретро-железа, поэтому минимум всегда современный.
3. **Фиксированный target_quality="high" и недооценка специфики движков** — для современных AAA иногда даёт меньше RAM, чем реальные требования.
