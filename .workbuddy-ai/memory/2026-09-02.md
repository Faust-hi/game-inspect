## Грабли, которые стоит помнить

- **`cmd.exe` нельзя вызывать** ни из Bash, ни из PowerShell-инструмента (блокируется
  политикой безопасности). Поэтому `start.bat` проверить запуском нельзя — пришлось
  разложить его на простые `run.bat` и проверять эквивалентными командами напрямую.
- **Vite слушает только `[::1]`**, а не `127.0.0.1`. Проверять нужно через
  `curl "http://[::1]:5173/"` либо `http://localhost:5173/`.
- **Bash-инструмент ходит через прокси**: без `curl --noproxy '*'` локальные адреса
  отдают 502/000.
- **Фоновые процессы из Bash-вызова с `&` погибают** после завершения вызова —
  нужно использовать `run_in_background: true`.
- **`//`-преобразование путей в Git Bash не работает** для флагов: `taskkill //PID`
  и `cmd //c` передаются буквально. Использовать PowerShell-инструмент или
  `MSYS_NO_PATHCONV`.
- PowerShell-инструмент в этой сессии **не возвращал stdout** — вывод команд
  (`Get-NetTCPConnection`) пришлось проверять через `netstat` в Bash.
