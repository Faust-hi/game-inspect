## Дополнения, обнаруженные при сверке

Подтверждённые новые детали сохранены отдельно, чтобы не выдавать их за прежнее совпадение: **N01** смешанная таксономия платформ seed; **N02** молчаливый пропуск ошибочных примеров seed; **N03** порядок функций меняет fingerprint; **N04** CPU при FG зависит от displayed target; **N05** шаги применения/примеры не показаны в карточке; **N06** связанный вес confidence/risk; **N07** укрупнённая группа custom; **N08** запрос опубликованных конфликтов не проверяет публикацию концов. N04/N05/N07 — пробелы, N06 — компромисс модели, N08 — статический риск целостности; не все восемь являются доказанными пользовательскими багами.

Не сохранены как достоверные: отсутствие RT-вклада; отсутствие 4K-множителя; мусорное число→0; отсутствие версий в fingerprint; фильтрация Vega 64; Alembic только по revision; инверсия quality_preservation; утечка draft-движка через проверенный публичный путь; отсутствие теста correction; «мёртвый» UE_NETWORKING; описанная внешним автором структура conflicts.py/Track1/Track2. Детальные опровержения находятся в COMPARISON.md.

Код приложения не менялся. Выводы сохранены для следующего этапа обсуждения/исправлений; гарантии точности и сроки из внешних отчётов не приняты без проверки.
