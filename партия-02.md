## 1. Half-Life 2 (2004, Valve) — AppID 220

- **Engine:** Source (debut release, 2004)
- **Format:** 3D | **World:** linear | **Scale:** medium
- **Platforms:** pc_windows (16.11.2004), Xbox (15.11.2005), Xbox 360 (Orange Box, 10.10.2007), PS3 (Orange Box, 11.12.2007 EA port), Mac OS X (26.05.2010), Linux (09.05.2013), Nvidia Shield (12.05.2014)
- **Targets:** 1080p / 60 fps
- **Object/NPC level:** medium / low | **Multiplayer:** DM only (HL2: Deathmatch 220, отдельный релиз декабрь 2004)
- **API:** DX9 (базовый Source engine)

### Features
- physics_simulation (VPhysics), character_animation (Faceposer), ai_pathfinding (NavMesh), post_processing, dynamic_shadows, vehicle_simulation

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| havok_physics_wrapper | Havok SDK с собственной обёрткой VPhysics для пропсов, QPhysics для NPC; интеграция в лиц-циклы движка | Стоимость лицензии; overhead конвертации на CPU |
| substance_material_system | материал задаёт физические свойства, звук шагов, friction, density автоматически | Ограниченный набор параметров |
| fixed_timestep_physics_60hz | детерминированный шаг 66.6 Гц для предсказуемой физики | Однопоточный скриптовый движок |
| sleep_wake_states | OBJ_AWAKE/STARTSLEEP/SLEEP — спящие объекты не симулируются | Расход на пробуждение для больших составных объектов |
| superman_gravity_gun_fix | ручной апдейт массы поднятого объекта для предотвращения бесконечного ускорения | Требует физического тюнинга; не универсально |
| hl2_faceposer_facs | FACS по Ekman — 40 Action Units, процедурная интерполяция через Channel-weights | Нет универсального фотореализма; видны "маски" |
| procedural_facial_animation_via_chris | автоматическая генерация выражений из текста (ранее Phoneme) | Требует тюнинга |
| navmesh_ai_pathfinding | навигационная сетка вместо вейпоинтов | Сложно строить для процедурных уровней |
| combined_action_puzzle_structure | боевая фаза + физический паззл чередуются в ритме | Узкие коридоры для компромисса |
| dispatchable_strider_combat | масштабные враги как конечные боссы уровней (Strider в City17) | Нагрузка на ИИ |
| provokable_ai (antlion, barnacle) | NPC реагируют на дистанцию/звук/свет, не на скрипты | Сложнее отладки |
| hdr_lighting_lost_coast_demo | HDR в Lost Coast (2005); stencil-histogram для совместимости с ps_2_b и MSAA | Banding артефакты |
| 64bit_native_port_2005 | декабрь 2005: нативный 64-bit engine для Windows XP Professional x64 | Не во всех сценах стабильнее 32-bit (Techgage) |
| HDR_FP16_phong_fresnel | Phong-spec и Fresnel-rim для Alyx; в пещерах Ep2 — полупрозрачная радиосити | Цена DX9 path, ps_2_b совместимости |
| full_voice_acting_3_party | актёры озвучки (Louis Gossett Jr., Robert Guillaume, Robert Culp) | Большой размер файлов локализации |
| steam_preload_distribution | предзагрузка зашифрованных файлов до релиза, разблокировка в дату выхода | Требование Steam-аккаунта с самого начала |
| steam_required_drm | retail-копии требовали Steam-активацию — скандал 2004 | Потеря offline-игры при проблемах со Steam |

### Инженерный паспорт

- **Min HW:** Pentium 4 2.0 GHz / Athlon XP 2000+, 512 MB RAM, DX9 GPU 64 MB
- **Rec HW:** Pentium 4 3.0 GHz / Athlon 64 3000+, 1 GB RAM, GeForce 6600 / Radeon X1300
- **Frame budget:** 33.3 мс (60 fps цель)
- **Streaming/IO:** loading screens между главами; внутри глав — BSP-потоковая подгрузка секторов
- **Engine limits:** **BSP компилятор VBSP — жёсткие лимиты**: MAX_MAP_ENTITIES = 2048 (активные динамические сущности), MAX_MAP_PLANES = 65536 (плоскости мира), visclusters (жёсткий лимит видимых кластеров, препятствует масштабированию локаций). BSP — статическая геометрия; physics sleep state экономит CPU
- **Mod support:** Source SDK официальный; Minerva, Black Mesa, SMOD, Garry's Mod
- **Antipiracy:** Steam-активация (2004 — революционно и скандально); pre-load DRM

### Баланс решений
- **Выгода:** Havok + VPhysics — физика как геймплей (gravity gun); Substance System — материалы = поведение; FACS — реалистичная мимика
- **Цена:** Superman fix массы gravity gun — ручной тюнинг; полная озвучка — огромный размер; BSP — нельзя деформировать мир; required Steam — потеря offline

### Инженерно значимые патчи (ПК)
- **Декабрь 2004:** релиз HL2: Deathmatch (отдельный standalone)
- **2005:** HL2: Lost Coast (бесплатный HDR-demo)
- **Декабрь 2005:** первый нативный 64-bit Source для XP x64 (HL2 + Lost Coast)
- **Июнь 2006:** Episode One (Source 2006, новая морфологическая анимация лица)
- **Октябрь 2007:** Episode Two (Source 2007, HDR + Phong)
- **The Orange Box (10.10.2007):** Episode One + Two + Portal + TF2
- **26.05.2010:** Mac OS X (Universal binary)
- **09.05.2013:** Linux (SteamPipe + native)
- **Январь 2022:** Steam Deck-оптимизированный UI
- **Ноябрь 2024 (20-летие):** Episode One+2 встроены в HL2; Steam Workshop; restored cut content; developer commentary; HL2 временно бесплатен

## 2. Half-Life 2: Episode One (2006, Valve) — AppID 380

- **Engine:** Source 2006
- **Format:** 3D | **World:** linear | **Scale:** small (короткий эпизод 4-6 часов)
- **Platforms:** Windows (01.06.2006), Xbox 360 (Orange Box 10.10.2007), PS3 (Orange Box 14.12.2007), Mac (26.05.2010), Linux (26.06.2013), Shield (15.12.2014)
- **Targets:** 1080p / 60 fps
- **Object/NPC level:** medium / low | **Multiplayer:** false

### Features
- ai_companion, dynamic_shadows, procedural_facial_animation, post_processing (HDR)

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| alyx_ai_companion | Alyx как комбатант с "personality code" — не повторяет фразы, реагирует на действия игрока | Требует тщательной настройки |
| gravity_gun_first_weapon | gravity gun получаешь сразу (не crowbar как в HL2) — паззл-ориентированный геймплей | Меньше традиционного FPS |
| enemy_tactics_ai_upgrade | Combine солдаты теперь приседают, чтобы уклониться от огня | Дороже на CPU |
| hdr_lighting_story_moments | HDR используется эпизодически для сюжетных моментов | Banding, требует stencil histogram (8-bit) |
| phong_fresnel_spec_alys | Phong-spec и Fresnel-rim для Alyx | Удорожание шейдеров |
| procedural_facial_animation_v2 | обновлённая FACS с динамической интерполяцией | Сложная отладка |
| dynamic_city17_destruction | город изменился после HL2 — разрушенные здания, инопланетная Xen-фауна | Долгая сборка уровней |
| integrated_tutorial_in_narrative | обучение интегрировано в сюжет, не отдельные уровни | Сложнее сценарной работы |
| script_driven_companion_cover | Alyx занимает укрытия и прикрывает игрока | AI overhead |

### Инженерный паспорт
- **Min HW:** аналогично HL2
- **Rec HW:** аналогично HL2 + 256 MB VRAM для HDR
- **Frame budget:** 16.6 мс (60 fps); HDR добавляет ~1-2 мс
- **Engine limits:** short campaign (~4-6 часов) — лимиты те же что Source 2006
- **Antipiracy:** Steam-активация

### Баланс решений
- **Выгода:** Alyx как живой компаньон (не scripted follower); gravity gun с самого начала для лучшей pacing
- **Цена:** HDR banding; компактный движок перенял ограничения Source 2006

### Инженерно значимые патчи
- **Январь 2022:** Steam Deck UI
- **Ноябрь 2024:** Episode One+2 встроены в HL2
- Июнь 2013: Linux-порт
- Май 2010: Mac-порт

## 4. Counter-Strike: Source (2004, Valve + Turtle Rock) — AppID 240

- **Engine:** Source (debut Source Engine release — вышел ДО HL2)
- **Format:** 3D | **World:** linear (арены) | **Scale:** small
- **Platforms:** Windows (07.10.2004), Mac (23.06.2010), Linux (02.2013)
- **Targets:** 1080p / 60 fps (CS:S в основном 100 fps на форумах того времени)
- **Object/NPC level:** low / low | **Multiplayer:** true (до 64 игроков, увеличено с 32 в оригинале)

### Features
- multiplayer_netcode, physics_simulation, post_processing (HDR с 2005)

### Инженерные решения

| Метод | Реализация | Цена |
|---|---|---|
| source_engine_ragdoll_physics | ragdoll-физика для тел вместо предопределённых death-animations | Больше расход CPU |
| |
| enhanced_physics_world | бочки, покрышки, бутылки физические; гранаты реалистично катят и рикошетят | Новая стоимость CPU для коллизий |
| cubemap_reflections | отражения через cube mapping — прицелы отражают окружение | VRAM cost |
| 3d_skyboxes | расширение видимого мира за пределы playable area | Удорожание рендера |
| bump_normal_specular_maps | bump/normal/specular mapping через DX9 | Требования к GPU |
| hdr_lighting_2005_update | HDR введён в декабре 2005, постепенно на картах | Stencil histogram стоимость |
| max_64_players | удвоение игроков с 32 (CS 1.6) до 64 | Серверная нагрузка |
| source_engine_2006_transition | переход на Source 2006 (Episode One) с исправлением багов и новыми фичами | Разрыв комьюнити на v34/новый |
| source_engine_2013_mp_transition | переход на Source 2013 MP branch в апреле 2013 + SteamPipe | Унификация кода |
| 64bit_migration_2025 | 18.02.2025 — переход на x64, обновлённый Source 2013 MP из TF2 | Старая кодовая база |

### Инженерный паспорт
- **Min HW:** Pentium 4 2.0 GHz / Athlon XP, 512 MB RAM, GeForce 6600 / Radeon X1300
- **Rec HW:** Core 2 Duo, 1 GB RAM, GeForce 8800 / Radeon HD 3870
- **Frame budget:** 16.6 мс
- **Streaming/IO:** цельные карты, загрузка 1-3 секунды
- **Engine limits:** **кризис сетевого тикрейта 2010**: перевод движка с фиксированных 100 Hz на унифицированные 66 Hz (ветка Orange Box) **сломал соревновательную физику распрыжки (bunny hop)** и вызвал раскол киберспортивного сообщества на сборки v34 и Steam-версию. **18.02.2025** — патч добавил аргумент `-vulkan` для рендерера Vulkan (DXVK-стиль), дополнительно к x64-миграции и объединению кодовой базы с TF2 Source 2013 MP.
- **Mod support:** Source SDK
- **Antipiracy:** Steamworks + встроенный anti-cheat (VAC)

### Баланс решений
- **Выгода:** ragdoll-physics, 64 игрока, HDR, Source-engine современные эффекты
- **Цена:** утеряна прецизионная recoil-система CS 1.6 (больше рандома), bunny hopping ограничен

### Инженерно значимые патчи
- Декабрь 2005: HDR постепенно на картах
- Декабрь 2005 — январь 2006: Turtle Rock ремейки 6 классических карт + bot support (предтеча L4D AI)
- Август 2006: новый radar, больше карт
- Ноябрь 2006: Dynamic Weapon Pricing (провалился — убран)
- **23.06.2010:** переход на Orange Box engine (Source 2006/2007 hybrid) — тикрейт заблокирован на 66
- 19.10.2011: Source MP branch
- 16.04.2013: Source 2013 MP + SteamPipe
- 18.02.2025: 32→64-bit, обновлённый Source 2013 MP из TF2, VScript, графические улучшения (первое крупное обновление за 12 лет)
