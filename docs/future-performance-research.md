# Исследования и проекты для будущего развития game-inspect

Сохранено 2026-09-07 по просьбе пользователя. **Статус: справочные идеи на будущее. Не реализовывать в рамках текущей задачи.** Это не утверждённый план разработки, не новые зависимости и не обещание точности. Ограничения README остаются действующими.

| Источник | Полезная идея | Что мешает прямому переносу |
|---|---|---|
| [GAMORRA, 2022](https://arxiv.org/abs/2204.11025) | Оценка нагрузки отдельно по стадиям графического конвейера с последующей оценкой времени кадра | Требуются поток команд API, параметры работы и калибровка. Средняя ошибка 9.45% в экспериментах авторов на D3D11 не относится к анкете game-inspect. |
| [Palladio Component Model, статья](https://www.sciencedirect.com/science/article/pii/S0164121208001015), [симулятор](https://www.palladio-simulator.com/) | Архитектура → компоненты/взаимодействия/потребление ресурсов → оценка производительности | Не готовая игровая модель; потребуются стоимости и сценарии работы игровых подсистем. |
| [Avionics Graphics Hardware Performance Prediction with Machine Learning, 2019](https://publications.polymtl.ca/4895/1/2019_Girard_Avionics_graphics_hardware_performance_prediction.pdf) | Контролируемые синтетические сцены для обучения и отдельная сцена для проверки | Ограниченная авиационная графика OpenGL SC, используется ML. Медианная ошибка менее 4 FPS не переносится на современные игры. |
| [Roofline, Berkeley](https://www2.eecs.berkeley.edu/Pubs/TechRpts/2008/EECS-2008-134.pdf) | Разделять предел вычислений и предел обмена с памятью; объяснять узкое место | Нужны объёмы работы и обмена данными; модель границ сама не предсказывает FPS всей игры. |
| [Epic Lumen Performance Guide](https://dev.epicgames.com/documentation/unreal-engine/lumen-performance-guide-for-unreal-engine?lang=en-US) | Паспорт решения: версия/режим/внутреннее разрешение/оборудование/стоимость подсистемы | Целевые бюджеты 4/8 мс относятся к описанным консольным сценариям Lumen при 1080p, а не к любому ПК и не ко всему кадру. |
| [AMD Radeon GPU Analyzer](https://gpuopen.com/rga/), [исходный код](https://github.com/GPUOpen-Tools/radeon_gpu_analyzer) | Анализ конкретных шейдеров и аппаратных ресурсов без запуска всей игры | Нужен код/представление шейдеров; это выходит за текущую анкету и не даёт требований всей игры. |

Возможное направление, требующее отдельного будущего решения: выбранные технологии и их интенсивность → работа по подсистемам → ограничения CPU/GPU/памяти → диапазон оборудования. Измерения эталонных сцен могут быть отдельным процессом подготовки базы без запуска пользовательской игры. Использование ML или анализа кода потребует отдельно пересмотреть соответствующие ограничения проекта.

Цель пользователя относится примерно к 70% допустимой относительной ошибке требуемой **производительности**, а не к имени модели, доле совпадений ±1 класс или автоматически к 30% ошибки. Ни одна сохранённая публикация не доказывает выполнение этой цели текущим проектом.
