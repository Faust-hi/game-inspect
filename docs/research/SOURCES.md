# Источники и проверяемые утверждения

Дата обращения: 2026-09-08. Читать этот реестр совместно с FINDINGS.md. `Документировано` означает подтверждение механизма или интерфейса в указанном материале, не измеренный выигрыш game-inspect. Просмотрены обозначенные разделы; полное независимое воспроизведение чужих исследований не выполнялось. Дата публикации указана только когда установлена; отсутствие даты/commit отмечено.

| S07 | [Unity batching](https://docs.unity3d.com/6000.0/Documentation/Manual/DrawCallBatching.html), Unity Technologies, 6000.0; Batch moving GameObjects / limitations | Dynamic batching выполняет работу на CPU; её стоимость может превысить экономию вызовов. Ручное объединение мешей и static batching не считать одним методом |
| S08 | [Godot GPU optimization](https://docs.godotengine.org/en/4.4/tutorials/performance/gpu_optimization.html), Godot, 4.4; 3D batching, Reuse shaders and materials, Pixel/fragment shaders | Число объектов без разнообразия материалов и pixel cost недостаточно. Объединённая геометрия теряет отдельное отсечение. Использовать причинные связи | Упрощённые общие формулировки документа не превращать в количественную модель архитектур GPU |
| S09 | [Godot CPU optimization, русский текст](https://docs.godotengine.org/ru/3.5/tutorials/performance/cpu_optimization.html), Godot, 3.5; Measuring performance / Threads | Исторический источник для измерения CPU, конкуренции за память и профилирования. Использовать в протоколе проверки | Историческая версия 3.5, не подтверждение конкретного поведения 4.4 и не универсальный коэффициент ускорения потоками |
| S10 | [Ray Tracing Performance Guide](https://dev.epicgames.com/documentation/en-us/unreal-engine/ray-tracing-performance-guide-in-unreal-engine?application_version=5.5), Epic / UE 5.5; BLAS Updates, TLAS Build | Различаются построение структур и traversal. Использовать отдельные параметры работы | Ни поколение CPU, ни фиксированный RT-ms из этой документации не следуют. Общая ссылка без версии открывала UE 5.8, поэтому для каталога использован вариант 5.5 |
| S11 | [PresentMon](https://github.com/GameTechDev/PresentMon), Intel/GameTechDev; README, описание компонентов | Захватывает CPU/GPU/Display длительности и задержки на Windows, использует ETW. Использовать как кандидат внешнего измерителя | Не реализован в runtime. README не доказывает точность каждого столбца или различение FG для любой версии игры. Commit не закреплён, запуск не выполнен |
| S12 | [Tracy](https://github.com/wolfpld/tracy), авторы Tracy; README | Кандидат инструментированного профилирования кадра. | S13 | [meshoptimizer](https://github.com/zeux/meshoptimizer), Arseny Kapoulkine и участники; Overdraw optimization / Simplification | Overdraw optimization допускает компромисс с vertex cache; упрощение имеет ограничения ошибки/топологии и может не достигнуть заданного числа индексов. Использовать как механизм и план малого эксперимента | Параметр threshold — ограничение алгоритма, не обещанный процент FPS. Не запускалось, точный commit не закреплён |
| S14 | [UE Distance Field Shadows](https://dev.epicgames.com/documentation/en-us/unreal-engine/using-distance-field-shadows-in-unreal-engine?application_version=5.5), Epic / UE 5.5; Steps / Directional Lights | Для directional lights можно разделить диапазоны CSM и distance fields; требуется подготовка mesh distance fields. | S15 | [Filament: Physically Based Rendering](https://google.github.io/filament/Filament.md.html), Google/авторы Filament; Roughness remapping and clamping / IBL | Реализация материала включает конкретные вычисления, точность и приближения.
